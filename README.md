# Portfolio

Mi portfolio personal: [mariopxz.com](https://mariopxz.com). Hecho con React, TypeScript y Tailwind CSS, con modo claro y oscuro y diseño responsive.

## Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS 4

## Contenido

Todo el texto está en `src/data.ts`: perfil, skills, experiencia, formación y proyectos. La interfaz está en `src/App.tsx` y los colores de cada tema en `src/index.css`.

- **Logos:** cada skill usa `public/logos/<nombre>.svg`.
- **Capturas de proyectos:** van en `public/work/`.
- **Contribuciones de GitHub:** se piden en vivo a [github-contributions-api](https://github-contributions-api.jogruber.de).
